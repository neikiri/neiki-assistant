Features Integration

Embeddable AI widget

Lightweight chat support for any website.

A framework-independent Web Component with Shadow DOM isolation, streaming replies, markdown, persistence, themes and a tiny integration surface.

View snippet
<neiki-assistant api="/chat"></neiki-assistant>

Built for embedding

Custom Elements and Shadow DOM keep the widget independent from host CSS and framework choices.

Conversation ready

Streaming responses, retry handling, keyboard controls, auto scroll and localStorage history are included.

Polished by default

Light, dark and auto themes share one customization layer through CSS variables and attributes.

Provider agnostic

The frontend sends messages to your backend endpoint. OpenAI, OpenRouter, Ollama or any custom stack can respond.

Install

One script and one element.

Ship the minified bundle from any CDN or CMS asset manager. No frontend build step is required by website owners.

<script src="https://cdn.neikiri.dev/neiki-assistant/neiki-assistant.min.js"></script>

<neiki-assistant
  api="https://example.com/api/chat.php"
  title="Support"
  language="en"
  theme="auto"
  accent="#2563eb">
</neiki-assistant>
